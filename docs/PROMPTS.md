# Evidências de uso de IA no desenvolvimento

Este arquivo registra exemplos de prompts utilizados durante o desenvolvimento. Use prints desta página e das conversas com IA como evidência para o trabalho.

## Prompt 1 - Planejamento da solução

Crie um plano detalhado para desenvolver uma aplicação web chamada Copiloto Corporativo Inteligente. A aplicação deve permitir perguntas em linguagem natural, usar uma base de conhecimento simulada, demonstrar agentes especializados e seguir boas práticas de governança de IA. Use ferramentas gratuitas e uma arquitetura simples para iniciante.

## Prompt 2 - Geração da interface

Crie uma interface em HTML, CSS e JavaScript para um chatbot corporativo com menu lateral, seleção de agentes, perguntas rápidas, histórico de conversa e botão para gerar resumo.

## Prompt 3 - Prompt de governança da IA

Crie um prompt de sistema para um copiloto corporativo que responda apenas com base na base de conhecimento, não invente informações, não solicite dados sensíveis e informe quando não houver informação suficiente.

## Prompt 4 - Backend Apps Script

Crie um backend em Google Apps Script que receba uma pergunta via POST, consulte a Gemini API com uma chave armazenada nas propriedades do script e retorne JSON para o frontend.

## Prompt 5 - README

Crie um README profissional para um projeto acadêmico chamado Copiloto Corporativo Inteligente, incluindo descrição, problema, solução, tecnologias utilizadas, ferramentas de IA, como executar, limitações e próximos passos.
